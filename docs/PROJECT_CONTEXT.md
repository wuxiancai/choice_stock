# 项目上下文

这是一个轻量 A 股盘后选股看板。每天 21:00（Asia/Shanghai）拉取最近交易日数据，计算 MACD、KDJ、BOLL、RSI、九转计数、主力资金和龙虎榜等可用信号；Web 首页显示最近五个交易日的行业涨幅、成交额与资金流。

首次运行需要复制 `.env.example` 为 `.env` 并写入 Tushare Token。点击“立即同步”或首次夜间任务会从 120 个开市日候选中回补至少 90 个实际有日线的数据日；尚未发布日线的日历日期会跳过。后续为增量同步：只补缺失或残缺交易日，并刷新最新日。板块历史快照也会按有效行数检查，残缺日期会在下次同步重试回填。系统不提供任何自动下单能力，所有结果仅供研究。


新增趋势突破/回踩策略保留旧日线启动推荐；使用沪深300环境、最近120个交易日复权因子和上市元数据。对排序后候选逐只调用3000积分内的Tushare财务审计意见和单股资产负债表，按公告日筛查非标审计和负净资产；缺失/接口失败则不展示为推荐。每日涨跌状态排除一字涨跌停。市场暂停时不开放候选；逾期债务、重大诉讼、监管立案和盘口可成交性仍需人工核验。
