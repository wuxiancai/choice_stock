# Handoff

## 当前状态

第一版已实现：可本地启动、可由 systemd 托管的 A 股盘后选股与行业资金流看板。`deploy.sh` 会自动检测 Python 3.12+；macOS 缺少时通过 Homebrew 安装，Ubuntu 缺少时通过 apt（必要时 deadsnakes PPA）安装，再创建 `.venv` 与安装全部项目依赖。

技术信号表现已覆盖量比、换手率、成交额、总市值、PE、PB 与涨跌幅，并可与评分、MACD、KDJ、RSI、布林位置、九转、主力净流入进行任意最小/最大值组合筛选。估值与量比来自 Tushare `daily_basic`；当前数据库中的历史信号需在下一次同步后重新计算才会填充新增字段，数据源无权限或缺值时页面显示 `—`。

`20260814` 修复了新增字段迁移后旧信号的 `pct_chg=NULL` 导致首页模板比较 `NULL >= 0` 并返回 500 的问题；页面会把该类历史缺值显示为 `—`。

页面最后新增“系统日志”：`sync_latest` 失败和页面/API 未处理异常会写入 SQLite `system_logs`，展示最近 50 条 ERROR（UTC 时间）；记录中的 Tushare Token 会脱敏。

`start.sh` 的启动提示中，变量后紧接中文标点必须使用 `${VAR}`；在 `set -u` 环境下裸 `$VAR` 可能被 shell 解析为包含全角符号的变量名。
