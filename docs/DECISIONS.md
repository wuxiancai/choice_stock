# 当前决策

- 调度使用应用内 APScheduler；生产由 systemd 保持进程存活。
- 21:00 任务按上海时区执行，周末/节假日由 Tushare 交易日历跳过。
- 指标需要至少 30 个交易日历史；历史不足的证券不产生技术评分。
- Tushare 账户按 3000 积分权限运行：仅可调用 `trade_cal`、`daily`、`daily_basic`、`moneyflow`、`stock_basic` 等不高于该门槛的接口；禁止调用 `moneyflow_ind_ths` 和 `moneyflow_ind_dc`。
- 当日行业资金流按东方财富、同花顺、腾讯的公开接口降级；至少 30 行且同时具备涨跌幅、主力净流入才视为成功，并记录实际来源与前置降级原因。
- 历史行业快照仅调用东方财富公开行业历史接口。AKShare 同花顺与腾讯仅提供当日快照，不能伪造为历史数据，状态中必须明确标注“未用于历史”。
